# 玻尔 Playground 参赛 Skill 集

八个 Skill，对应北化分站赛第一期八道赛题。每个目录是一份可提交的 Skill 包，含 `SKILL.md`、脚本、示例与资源清单。

| 目录 | 赛题 |
|-|-|
| `skills/citation-manager` | 写作04 参考文献与引用管理 |
| `skills/methods-params` | 写作09 方法与实验章节写作 |
| `skills/intro-related-work` | 写作08 引言与相关工作写作 |
| `skills/latex-build-guard` | 写作13 LaTeX 写作与编译 |
| `skills/pdf-reader-structure` | 阅读01 文献文档解析 |
| `skills/nanopub-split` | 阅读14 Nanopublication |
| `skills/graph-jats` | 阅读15 文献知识图谱构建 |
| `skills/paper-notes-structured` | 阅读10 文献总结与结构化笔记 |

每个包都能独立运行，不依赖本仓库外的文件。

## 用法

进入任一目录，读 `SKILL.md` 的「调用」一节，按示例命令执行。
