# 引言与相关工作写作：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| 通用对话模型 | 能写通顺引言，但常补不存在文献、空白段无引用支撑 |
| 文献综述工具 | 按关键词聚类，不给引用与论断的一一对应 |
| 模板式写作 | 四段填空，容易变成空转铺垫 |

## 本 Skill 的做法

- 四部分骨架加引用双向差集：bib 有而未被引、引用了而 bib 无
- 相关工作按原文出现的维度词分组，无维度词时不编名
- 贡献条目只挂原文真实出现的 Fig./Table/Section 标记，挂不上写待作者补

## 做不到的部分

- 不检索新文献，只整理已有 bib 与病稿
- 原文没有维度词时只归一组并如实说明
- 不判断他人工作转述是否忠实，那需要读原文献

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
