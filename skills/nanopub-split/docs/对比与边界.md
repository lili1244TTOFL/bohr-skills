# Nanopublication：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| nanopub-java / nanopub-py | 做发布与签名，不做断言抽取 |
| SciSpacy / OpenIE | 通用三元组抽取，不保证科研粒度与证据最小性 |
| 人工标注 | 质量高但不可复用 |

## 本 Skill 的做法

- 一句一断言，只承一个关系；超阈值句子按分句切开，切不开进 unresolved.md
- 每条断言带最小证据片段与行列区间，来源链路到论文与作者年份
- 中英各一套关系规则、共用关系名

## 做不到的部分

- 不判断断言真假，只保可判断可回指
- 关系词表外的句式会漏，真实英文摘要覆盖率约 0.375
- 不做跨篇去重

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
