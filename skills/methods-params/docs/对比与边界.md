# 方法与实验章节写作：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| 实验记录工具 W&B / MLflow | 记录参数与曲线，不产出可读章节 |
| 论文模板 | 给结构与占位提示，参数与正文需作者手工对齐 |
| 通用对话模型 | 能写章节，但易补出配置里没有的数值 |

## 本 Skill 的做法

- 参数只从配置文件与日志取，每条带文件行号来源，取不到记 unknown
- 六类要素逐类盘点，缺项进 gaps
- 对照实验写出基线对象、对照条件、评价指标与指标值，各带来源行号

## 做不到的部分

- 不从正文散文反推参数，那正是题面禁止的做法
- 步骤只能从代码或日志识别，纯文字材料时标待作者确认
- 不做统计检验，只记录指标与来源

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
