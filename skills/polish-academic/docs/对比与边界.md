# 学术语言润色：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| LanguageTool | 规则词库大，偏语法拼写，不追踪限定强度与数字引用是否被改坏 |
| Grammarly | 通用英文写作助手，不产出逐条码/片段/理由的可核记录 |
| 作者手工通读 | 质量上限最高，但给不出守恒项的前后计数 |

## 本 Skill 的做法

- 改前改后两侧同口径计数：数字、单位、引用、图表指向、否定、加强词、留有余地词
- 问题带码 D01–D10 与段/句位置，改动记录可逐条核
- 无外部改后稿时用内置规则改出可交付版本，规则命中逐条入 result.json

## 做不到的部分

- 只做词面与句式修复，不改论证结构
- 不做语义判断，改写后是否更通顺需人看
- 术语一致性依赖外部术语表

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
