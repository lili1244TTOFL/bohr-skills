# 评分口径

本文件解释 `run.py` 的判定为何这样打分，供复核者对照。

| 维度 | 判据 | 本实现怎么落地 |
|-|-|-|
| 改得对 | 语法、搭配、冗余、口语、长句、名词化是否被真正改掉 | D01–D10 逐条检测，每条给码、片段、段句位置、理由 |
| 说得像 | 术语是否全篇统一 | T01：术语表锁定后回扫改后稿，列不一致清单 |
| 没改坏 | 数字、单位、引用、图号、否定、限定强度是否保持 | K01 四项计数、K02 加强词与留有余地词只许不减 |
| 讲得清 | 每处修改是否有原文、改文、类型、理由 | `changes.md` 每行带码、片段、位置、理由、置信度 |

状态含义：`success` 有改后稿且无漂移；`partial` 有改后稿但有漂移；`needs_polish` 未产出改后稿。
