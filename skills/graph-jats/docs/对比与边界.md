# 文献知识图谱构建：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| Neo4j 加手写抽取 | 图数据库强，抽取与证据绑定需自建 |
| SemRep / SciIE | 生物医学关系抽取成熟，跨篇对齐弱 |
| LLM 直出三元组 | 快，但常补出原文没有的实体与因果 |

## 本 Skill 的做法

- 两篇材料各自独立来源入图，根 DOI 与标题作者不串篇
- 每条节点与边带 source_id 与 paragraph_id 与原引短句
- 合并与冲突分开记：确认合并给依据，同名词不同对象 keep_separate

## 做不到的部分

- 材料只有两份 JSON 时不谎称有真实论文，manifest 标 example
- 不做增量更新的自动重排，只记录新增与冲突
- 实体类型限题面列出的六类

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
