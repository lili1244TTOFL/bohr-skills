# 文献翻译：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| DeepL / Google 翻译 | 段落质量高，术语全篇一致性需人工校 |
| CAT 工具 | 术语库与对齐成熟，重客户端难脚本化 |
| 通用对话模型 | 能整篇翻，长文会漏段、术语漂移 |

## 本 Skill 的做法

- 术语表锁定后全篇回扫，一致率给数值与不一致清单
- 段号一一对应，译文按段回填，漏译与错位可检出
- 数字、引用编号、否定、限定四项改前改后同口径计数

## 做不到的部分

- 不调用模型：无外部译文时用术语锁定替换产出草案，并另交待译清单
- 不做指代消解
- 术语按子串匹配，不做词形还原

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
