# 逐段翻译规则

本文件给调用方模型用：按 `segments.jsonl` 逐段翻译，遵守下列约束。

## 输入

`segments.jsonl` 每行：

```json
{"uid":"P001S002","pid":"P001","sid":2,"page":1,"text":"...","len":88,"cjk":false,
 "protected":{"numbers":["2"],"citations":["[1]"],"figtab":["Fig. 2"],"formulas":[],"negations":1}}
```

`glossary.md` 每行：`term<TAB>target<TAB>note`；`target` 为空表示尚未确定，遇到时列进 `gaps`。

## 逐段要求

1. **段号不变**：一条原文对应一条译文，`uid` 原样写回；不合并、不拆段、不跳段。
2. **术语锁定**：`glossary.md` 里的源术语出现时，必须使用对应译名，全篇不改。
3. **受保护片段原样保留**：`numbers`、`citations`、`formulas`、`figtab` 逐字照抄，
   数字不要换写法（`1,200` 不要写成 `1200`，`15%` 不要写成 `百分之十五`）。
4. **否定与限定**：原文的否定（not/no/never/without/fail to）与限定（only, at least, up to）
   必须在译文中出现，不得省略或改成肯定。
5. **指代与关系**：it/they/this/these 指代的对象要在译文中写明；因果、让步、转折不得丢。
6. **不增不减**：不补充原文没有的解释、例子、结论；不确定处保留原词并标 `[待确认]`。
7. **单位与符号**：`mM`、`µL`、`°C` 等保持原符号，不译成中文单位名。

## 输出

`targets.jsonl`，每行一条：

```json
{"uid":"P001S002","text":"译文","note":"术语或处理说明，可选"}
```

## 自查（提交前）

1. 行数 = `segments.jsonl` 行数
2. 每条 `uid` 唯一且与原文一致
3. 每条 `text` 非空
4. 术语表条目在译文中出现
5. 受保护片段在译文中逐字出现

## 批次与预算

每批 8–12 段，批次之间不重叠；每批带上前一批已确定的术语，保持上下文连续。
108 段按 10 段一批为 11 次请求，在 64 次预算内。
