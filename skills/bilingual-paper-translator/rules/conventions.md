# 约定与判定线（v3.0.0）

本文件是 `run.py` 与 `SKILL.md` 共用的口径来源。改判据要同时改这里、`SKILL.md` 的 Q 表与 `run.py`，
否则机检的码表比对（doc ↔ code）会不一致。

## 1 术语表格式

Markdown 表格，第一行是表头，列顺序固定：

| 原文 | 译名 | 禁用译名 | 备注 |
|-|-|-|-|
| working memory | 工作记忆 | 工作内存、操作记忆 | 按认知心理学习惯 |
| reaction time | 反应时 | 反应时间 | 不译作「反应时长」 |

- 前两列必需：原文（大小写不敏感，子串匹配）、译名（译文里必须原样出现）。
- 第 3 列可选：禁用译名，用 `、,，/;；` 分隔；命中即 Q05。若禁用串落在正确译名内部
  （如 `记忆负荷` 落在 `工作记忆负荷` 里）不算违规。
- 第 4 列可选：备注，只进 `bilingual.md` 与 `verify.json`，不参与判定。
- 表头行、分隔行、`原文/source/en/术语/term` 开头的行会被跳过，不当作条目。
- 术语表可持续追加：同一条目多次出现只写一次；同一原文只取第一次出现的行。
- 不接受 `.tsv`（平台预检拒该扩展名），用 `.md` 表格。

## 2 段号、句号与字符区间

- 段号 `S001`、`S002`…按原文出现顺序编号，一次运行内稳定；重跑同一输入编号不变。
- 句号 `S001.01`、`S001.02`…是段内句序，句边界规则：`.!?` 后接空白或文本结束；
  `。！？；` 直接结束（中文不加空格）；`e.g. / i.e. / et al. / Fig. / Eq.` 等缩写与
  `1.5` 这类小数点不切句。
- 字符区间是**原文的 UTF-8 字符下标，左闭右开**，不含段首尾空白；跨行段落保留原始换行，
  区间仍然连续，可按 `char_start/char_end` 回原文截取。
- 页码：原文含分页符 `\f`（`pdftotext -layout` 会保留）时按 `1 + 前序分页符数` 计；
  没有分页符就写 `null`，不猜页码。

## 3 对齐约定

- 段级：`targets.txt` 里一段对应一个段号。推荐写 `### S001` 段号标记（顺序无关、缺段可检出）；
  没有标记时退回「按空行顺序」配对，段数不等会报 Q02 并在 `gaps` 里写明配对方式。
- 句级：译文按句序对齐原文句；句数不等时对齐到 min(句数)，多出/缺失的句标
  「（未对齐）」并进 `manual_check`（`kind=句边界`），不假装一一对应。
- 公式段、参考文献条目按惯例原样保留：不参与术语回扫、不计未译残留、句级对齐仍需人工看。

## 4 未译与待确认标注规则

`labels`（脚本标注，不改变 status 的只有「词典项」这一层；未译类会改变 status）：

| 标注 | 触发条件 | 后果 |
|-|-|-|
| 未译 | 该段没有译文 | status=partial |
| 未译残留 | 译文与原文拉丁词重合 ≥80%（公式/参考文献段除外） | status=partial |
| 规则草案 | 该段译文来自内置规则（术语替换，语序未动） | 记 `change_records` |
| 术语未锁定 | 源段含术语但译文未见指定译名 | 计入 Q01 |
| 禁用译名 | 译文出现第 3 列的禁用串（未被正确译名覆盖） | 计入 Q05 |
| 跨页段 | 该段区间含分页符 | 提示带上一页末尾上下文 |

`manual_check`（需人工确认清单，不改变 status）：指代、句边界不一致、断词连字符、
拉丁词残留 50–80%、以及每一条 Q 码的命中项。清单逐条给段号与可直接定位的原文。

## 5 判定线（全部「完全相等」，没有可放宽的阈值）

| 码 | 判据 | 通过线 |
|-|-|-|
| Q01 | 术语一致率 = 该用指定译名的段数 / 命中术语的段数 | 必须 = 1.0 |
| Q02 | 段区间无交叠、无重复段（≥40 字符）、非空白字符覆盖率 = 1、外部译文段数 = 原文段数 | 全部满足 |
| Q03 | 逐段比较数字多重集、否定计数、限定/模糊计数 | 每段完全相等 |
| Q04 | 逐段比较「数字+单位」配对，中英单位按下表归一到同一 canonical | 每段完全相等 |
| Q05 | 禁用译名出现次数 | 必须 = 0 |
| Q06 | 图表编号、公式编号、行内公式、公式核心表达式是否原样保留 | 每段完全相等 |

- 单位归一（节选）：`毫升/ml→ml`、`毫克/mg→mg`、`小时/h→h`、`分钟/min→min`、`秒/s→s`、
  `天/day→d`、`周/week→wk`、`年/岁/year→yr`、`℃/摄氏度/°C→c`、`%→%`、`厘米/cm→cm`。
  未收录的单位不会折算，只按数字参与 Q03，并在 `gaps` 里保留原始写法。
- 不允许用「把阈值调低」过关：Q01–Q06 都是精确相等；要消除命中项只能改译文或走
  `acknowledged.json`（见 §6）。

## 6 人工确认豁免（`acknowledged.json`）

脚本**从不自己写**这个文件；它只能由人或调用方模型在核对原文后提供：

```json
[
  {"code": "Q03", "seg": "S003", "reason": "suggest 译作「认为」属有意弱化限定，已对照原文确认"}
]
```

- `reason` 为空的条目不生效；`seg` 省略表示该码全部命中项。
- 生效后该条 `problems[].acknowledged=true`，并在 `result.json.change_records` 记一条。
  未确认的命中项仍使 status=partial，未译残留即使确认也不改变 partial。

## 7 分段规则

1. 先按空行切段（保留原文，不重排、不做空白规范化）。
2. 若空行过少（段数 ≤ 行数/40）或单段 > 3000 字符，改按句群切：每段 ≤ 4 句且 ≤ 1200 字符，
   `segments.json.segmented_by` 记明用了哪种策略。
3. 角色判定：`title / heading / abstract / body / caption_fig / caption_tab / table /
   equation / reference`，供完整性清点（图表题注、表头、公式、参考文献是否都在）。
4. 章节名（Abstract/Introduction/Methods/Results/Discussion/Conclusion/References 及中文
   对应）落到 `section` 字段，用于核对「标题/摘要/正文/图注/结论里同一术语是否同一译名」。

## 8 评分表（自检口径，非官方成绩）

官方对照由平台生成，本表只说明脚本自己算的是什么、通过线在哪：

| 指标 | 计算方式 | 通过线 | 落在哪 |
|-|-|-|-|
| 术语一致率 | 用对指定译名的段数 / 命中术语的段数 | 1.0 | `verify.json.term_consistency.rate` |
| 段完整率 | 进入分段的非空白字符 / 原文非空白字符 | 1.0 | `verify.json.continuity.coverage` |
| 段序正确 | 区间单调、无交叠、无重复段 | 是 | `verify.json.continuity` |
| 事实保真 | 数字/单位/引用/图表编号/公式逐段相等 | 是 | `verify.json.problems` |
| 可回指 | 每段/每句都有字符区间与页码 | 是 | `segments.json`、`bilingual.md` |

`examples/defects` 是自造退化样本，用来验证 Q01–Q06 六码都能触发（六码全命中才算通过自查），
它不是对照成绩，也不冒充组织方固定案例。

## 9 复用与维护

- 换学科：只换术语表与译文；分段、句切、标记保护、核验口径与学科无关。
- 换语言：`UNIT_ALIAS` 加单位别名，`NEG_ZH_WORDS`/`HEDGE_RE` 加该语言的否定与限定词表。
- 加判据：在 `run.py` 新增 Q 码 → 同步 §5 表与 `SKILL.md` Q 表（机检会比对 doc ↔ code）。
- 版本：`run.py` 3.0.0 / 本文件 v3.0.0；`result.json.manifest.rules_version` 记明。
