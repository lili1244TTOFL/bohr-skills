# Working memory load and reaction time in sleep-restricted adults

Abstract

We examined 24 participants after 5 h of sleep restriction. Working memory load was increased in three steps, and reaction time was recorded for 12 min [1]. No significant change appeared in accuracy, but the n-back task error rate rose by 0.8%.

## 1 Introduction

Sleep restriction is common in shift work (Smith et al., 2019). Previous studies reported slowed reaction time under working memory load. It remained unclear whether the n-back task captures this slowing [2,3].

## 2 Methods

2.1 Participants

Twenty-four adults (age 22.4 ± 1.8 years) completed the study. All participants gave written consent.

2.2 Procedure

Working memory load was set to three levels, and reaction time was measured after each block. We fitted the linear model

RT = a + b × load   (1)

with load in arbitrary units (a.u.). The n-back task was administered twice per session.

## 3 Results

Reaction time increased from 512 to 634 ms (Table 1), i.e. by 122 ms. The effect did not differ between sessions [4]. Accuracy fell slightly but remained above 90%.
