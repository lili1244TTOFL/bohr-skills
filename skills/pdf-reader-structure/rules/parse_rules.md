# 解析判据与阈值

本文件是 `pdfparse.py` / `tables.py` 的规则依据。改阈值要和这里同步。

## 1. 字符块 → 行

| 参数 | 值 | 说明 |
|-|-|-|
| 基线容差 | `max(1.5, 0.35 × 字号)` | 同一行的多个文字块基线差在此范围内 |
| 水平间距 | `≤ max(8, 2 × 字号)` | 超过则视为跨栏或分栏断开，另起一行 |
| 宽度估计 | 中文 1.0×字号/字，西文 0.52×字号/字 | 用于判栏与通栏判断 |

落在这两条内的块按 x 排序拼接；拼接时块间补一个空格（两侧都无空格时）。

## 2. 判栏

| 参数 | 值 |
|-|-|
| 搜索范围 | 页宽的 30%–70% |
| 每侧最少行数 | 3 |
| 跨分界行上限 | `max(2, 15% × 行数)` |
| 判据 | 左右两侧行数和最大、跨分界行最少的位置 |

找不到合法分界 → 单栏。三栏以上：同一分界规则在子区域内递归。

## 3. 阅读顺序

1. 不属于任何栏的行（通栏标题、页眉页脚）先按 y 从上到下输出。
2. 再按栏从左到右，栏内自上而下。

这样左栏读完才读右栏，不出现"左栏第一行接右栏第一行"的拼接。

## 4. 角色判定（按顺序）

| 顺序 | 正则/条件 | 角色 |
|-|-|-|
| 1 | 行尾 `(数字)` 或 `（数字）` | `formula` |
| 2 | `^\s*[-–—]\s*\d+\s*[-–—]\s*$` | `page_number` |
| 3 | `^\s*(图|表|Figure|Fig\.?|Table)\s*[0-9A-Z]` | `caption` |
| 4 | `^\s*(\[\d+\]|\d+\.)\s+\S` | `reference` |
| 5 | 字号 ≥ 正文中位数 × 1.15，或字体名含 Bold；长度 ≤ 90；不以 `。 . ; ；` 结尾 | `heading` |
| 6 | `^\s*\d+(\.\d+)*[\s.、]\s*\S` 且长度 ≤ 60 | `heading` |
| 7 | 其余 | `body` |

标题层级：字号 / 正文中位数 ≥ 1.6 → 1 级；≥ 1.3 → 2 级；其余 3 级。

## 5. 页眉页脚

| 条件 | 值 |
|-|-|
| 位置 | 页面高度 8% 以内（上/下） |
| 重复 | 同一文本出现在 ≥ 60% 页，且长度 < 100 |
| 处理 | 标 `header`/`footer`，不写入正文 |

## 6. 表格网格

| 条件 | 值 |
|-|-|
| 线段来源 | 内容流 `m/l S`（描边线）与 `re S/f`（矩形） |
| 合并容差 | 坐标差 < 2.0 |
| 表格判据 | ≥ 2 条水平线且 ≥ 2 条垂直线 |
| 单元格 | 相邻线围成的矩形；文字按中心点（x + 0.3×字号×字数，y + 0.35×字号）归属 |
| 未归属 | 进 `unassigned`，不并入相邻格 |

输出 Markdown 时首行为表头，两行线不输出。

## 7. 公式编号

- 编号必须位于行尾：`(1)`、`（1a）`。
- 若编号独占一行且与上一行基线差 ≤ 4，合并到上一行，`formula_no` 取编号。
- 上下标：字号比正文小 15% 以上的字符视为上下标，保留原字符，不改写成 LaTeX。

## 8. 质量标记

| 指标 | 阈值 | 处理 |
|-|-|-|
| 缺字比例 | U+FFFD、`□` 占比 > 2% | `gaps` 记一条 |
| 无文字层 | 该页无字符块且无表格 | `gaps` 记页号 |
| 页覆盖 | 解析页数 < 总页数 | `checks["页覆盖"]` 置 false |
