# 解析判据与阈值

本文件是 `pdfparse.py` / `tables.py` 的规则依据。改阈值要和这里同步；默认
引擎是 layout（`scripts/layout.py`），coords 引擎只在显式 `--engine coords` 时使用。

## 1. 字符块 → 行

| 参数 | 值 | 说明 |
|-|-|-|
| 基线容差 | `max(1.5, 0.35 × 字号)` | 同一行的多个文字块基线差在此范围内 |
| 水平间距 | `≤ max(4.0, 0.6 × 字号)` | 超过则视为跨栏或分栏断开，另起一行 |
| 宽度估计 | 中文 1.0×字号/字，西文 0.52×字号/字 | 用于判栏、bbox 与标题宽度 |

落在这两条内的块按 x 排序拼接；拼接时块间补一个空格（两侧都无空格时）。

## 2. 判栏

layout 引擎（默认）：

| 参数 | 值 |
|-|-|
| 段切分 | 行内连续 ≥5 个空格或制表符 |
| 主栏 | 出现次数最多的段起始列（按 8 列取整） |
| 副栏 | 与主栏相距 ≥20 列、占比 ≥15%，且与主栏在同一视觉行共现 ≥2 次 |
| 表格 | 单元格文字先按 `cell_texts` 从段里剔除，再聚栏 |

coords 引擎（`--engine coords`）：

| 参数 | 值 |
|-|-|
| 搜索范围 | 页宽的 30%–70% |
| 每侧最少行数 | 3 |
| 跨分界行上限 | `max(2, 15% × 行数)` |

找不到合法分界 → 单栏。正文宽度 < 页宽 45% 的单栏页写 `gaps` 提示栏序未验证。

## 3. 阅读顺序

1. 表格单元格文字从正文段里剔除，聚栏时不参与计数。
2. 再按栏从左到右，栏内自上而下。

这样左栏读完才读右栏，不出现"左栏第一行接右栏第一行"的拼接。

## 4. 角色判定（按顺序）

| 顺序 | 正则/条件 | 角色 |
|-|-|-|
| 1 | 行尾 `(数字)` 或 `（数字）` | `formula` |
| 2 | `^\s*[-–—]\s*\d+\s*[-–—]\s*$` | `page_number` |
| 3 | 行首 `图/表/Figure/Fig/Table` + 数字，且数字后不是小写词 | `caption` |
| 4 | `^\s*\[\d+\]\s+\S` | `reference` |
| 5 | `^\s*\d+(\.\d+)*[\s.、]\s*\S` 且长度 ≤60、不以句末标点结尾 | `heading` |
| 6 | 全大写且长度 ≤90 | `heading` |
| 7 | 长度 ≤60 且命中 Abstract/引言/方法/结果/参考文献 词表 | `heading` |
| 8 | 字号 ≥ 正文 1.5 倍且长度 ≤200 | `title` |
| 9 | 字号 ≥ 正文 1.15 倍且长度 ≤120 | `heading` |
| 10 | 其余 | `body` |

标题层级：编号点数 +1（`1.`→1 级，`1.1`→2 级）封顶 3；词表标题（Abstract、
References 等）记 1 级；其余 2 级。

## 5. 页眉页脚

| 条件 | 值 |
|-|-|
| 位置 | 页面高度 8% 以内（上/下），按视觉行号或 bbox 判 |
| 重复 | 同一文本出现在 ≥ 60% 页（至少 2 页），且长度 < 100 |
| 处理 | 标 `header`/`footer`，不写入正文 |

## 6. 表格网格

| 条件 | 值 |
|-|-|
| 线段来源 | 内容流 `m/l S`（描边线）与 `re S/f`（矩形） |
| 合并容差 | 坐标差 < 2.0 |
| 表格判据 | ≥ 2 条水平线且 ≥ 2 条垂直线 |
| 单元格 | 相邻线围成的矩形；文字按中心点（x + 0.3×字号×字数，y + 0.35×字号）归属 |
| 未归属 | 进 `unassigned`，不并入相邻格；**当前未接进 gaps** |

输出 Markdown 时首行为表头，两行线不输出。

## 7. 公式编号

- 编号必须位于行尾：`(1)`、`（1a）`。
- layout 引擎：编号独占一段且与上一块同一视觉行，合并到上一块，`formula_no` 取编号。
- coords 引擎：编号独占一行且与上一行基线差 ≤ 4，合并到上一行。
- 上下标：**未实现**。字号比正文小 15% 以上的字符只保留原字符，不改写成 LaTeX。

## 8. 定位框

| 情形 | bbox 来源 |
|-|-|
| 段文本能在 visitor 字符块里匹配到 | 实测 `x0/x1/y`，`size` 取该行字号 |
| 匹配不到 | 推算框（页宽 × 行首列 / 100，页高 − 12 × 行号），并置 `bbox_est=True` |

## 9. 质量标记

| 指标 | 阈值 | 处理 |
|-|-|-|
| 缺字比例 | U+FFFD、`□` 占比 > 2% | `gaps` 记一条 |
| 无文字层 | 该页无字符块且无表格 | `gaps` 记页号 |
| 页覆盖 | 解析页数 < 总页数 | `checks["页覆盖"]` 置 false |

## 10. 判断层：块归属章节（由调用方模型判）

脚本只给候选：阅读顺序上最近的标题、下一个标题、前置部分。归到哪一节是模型的事。

| 判断层键 | 含义 |
|-|-|
| `unit` | 固定 `块归属章节` |
| `n` / `filled` / `pending` | 待判块数（不含图表/公式）/ 已判 / 未判 |
| `source` | 读的是哪个 `judgments.json`；没填写「只给候选与脚本默认归属」 |
| `exempt` | `caption` / `table` / `formula` 块：题面不要求理解科学含义，按阅读顺序由脚本定 |
| `items[]` | `id`（`P<页>-<序>`）、`page`、`role`、`原文`、`候选`、`脚本归属`、`value`、`basis`、`filled_by`、`status`、`in_candidates`、`basis_verbatim` |
| `mapping` | 指向 `block_sections.json`：全量块→节 |

填写格式：`{"items":[{"id","section","basis","filled_by"}]}`，`section` 必须取自该块候选，`basis` 必须是该块原文的子串。
判断单：`--out/block_section_worklist.md`。没填的块 `value=pending`，`gaps` 记条数。
