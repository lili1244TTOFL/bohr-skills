# 文献文档解析：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| pdftotext | 快，双栏会串栏，不输出块坐标 |
| GROBID | 学术 PDF 结构化强，需 Java 栈与模型文件 |
| PyMuPDF | 能取块坐标，阅读顺序与表格结构仍需自建 |

## 本 Skill 的做法

- 栏数判定后按列聚块再排序，双栏不串栏；表格单元格先剔除再聚栏
- 每块带 page 与实测 bbox 与字符区间，可回原文定位
- 无文字层页写 unreadable.md 列出位置，不猜不补

## 做不到的部分

- 扫描件与图片型表格不做 OCR，如实标未覆盖
- 公式只保符号与上下标字符，不做公式语义识别
- 三栏及以上版式未验证

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
