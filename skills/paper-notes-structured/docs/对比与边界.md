# 文献总结与结构化笔记：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| Zotero 笔记 | 随手记，不做与论文章节的对应校验 |
| 卡片模板工具 | 字段固定，来源回指靠手工 |
| 通用对话模型摘要 | 压缩后的通读摘要，锚点多为笼统出处 |

## 本 Skill 的做法

- 按论文自身章节切分，笔记骨架与章节一一对应
- 每条笔记带 page 与块与字符区间锚点，可回原文
- 研究问题、数据、方法条件、主要发现、局限五项逐项盘点

## 做不到的部分

- 不做图表数值抽取，只记位置与题注
- 不判断笔记内容是否比原文更准确
- 跨文献比较不在本包范围

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
