# LaTeX 写作与编译：与现有方案的边界

题面「创新增益」要求证明创新点相对已有方案的边界与价值。本文件逐项列出：现有做法、本 Skill 的做法、以及做不到的部分。

## 现有方案

| 方案 | 局限 |
|-|-|
| chktex / lacheck | 查语法与常见笔误，不产出修好的源码 |
| latexmk | 驱动编译并逐条报错，但不自动修 |
| Overleaf 在线编辑 | 交互式报错，不能离线批量处理 |

## 本 Skill 的做法

- 检查后由 autofix 直接改写 .tex：重复 label 改名、缺 label 就近补、缺 caption 补占位、缺图生成占位框
- 产出 diff、fixes.md、reproduce.md，每处修复带码与依据
- 编译参数改为收集全部错误，不因第一条错误停住

## 做不到的部分

- 本机无 TeX 时不谎称编译通过，记 no_tex_distribution 并单列
- 不改正文文字、数字与公式，只修结构与缺失项
- 不做版式审美调整

以上边界都能在包内核对：做不到的项在 `result.json` 的 gaps 或 `SKILL.md` 的限制节里逐条列出。
