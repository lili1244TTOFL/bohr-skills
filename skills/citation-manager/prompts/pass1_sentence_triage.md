# 提示词：句子引用分流（请求 1）

## 任务

输入为编号句子（可能带上下文列）。逐句判定该位置是否需要引用标记。不查库，不编号，不改写。

## 输入

1. `rules/paper_sections.md`
2. `pass1_input.txt`，每行 3～4 列，Tab 分隔：

```
P004:S002	intro	已有研究表明，慢性睡眠限制会导致注意力下降。
P002:S001	caption	图 1 两组正确率对比（数据来自本研究）	前一段末句 / 后一段首句
P004:S001	table	表 1：组别 | 正确率	[表格内容，只读]
```

第二列是脚本判定的章节：`abstract/intro/related/method/results/discussion/conclusion/limits/caption/table/decl`。第三列是句子或表格行；第四列是题注上下文或只读标记。

## 判定步骤

1. 读 `rules/paper_sections.md` 第 3 节判定顺序。
2. 逐行判定，按第 5 节格式输出。
3. 末行给汇总。

## 约束

- 类别四值：`CITE` `OWN` `STRUCT` `AMBIG`；理由码取 `rules/paper_sections.md` 第 4 节。
- 句首 20 字逐字复制，不改不译；表格行照抄。
- 每行输入对应一行输出，不漏不多；一行一个类别。
- 不输出编号、文献条目、推荐文献；不新增原文以外的事实。

## 图、表与题注

- `table` 行是**只读上下文**：判 `STRUCT`（表内数字是本文数据，不引），不参与插入。
- `caption` 行看第四列上下文判断：
  - 图表数据是本文测得 → `OWN`/`RC5`，不标；
  - 写了"改自/引自/数据来自 [n]" → `CITE`/`RC3`；
  - 与文献对比、引用他人图表 → `CITE`/`RC4`；
  - 只有图题、无来源线索 → `STRUCT`/`RC8`。
- 图片本身不可读，只有题注与上下文可用；不凭图号猜内容。

## 信号与边界

- 本文数据、本文结论、本文方法 → `OWN`；他人数据、方法、标准、数据集、量表 → `CITE`。
- 软件、仪器、统计工具不引。
- 已有标记保留，不删不换号；标记挂在本文数据上 → `AMBIG`/`R6`。
- 无信号或已被上文引用覆盖 → `AMBIG`/`R9`，默认不新增。
- 摘要、关键词、题名不标注。

## 输出

```
P004:S002|CITE|RC1|已有研究表明，慢性睡眠限制会
P002:S001|caption|OWN|RC5|图 1 两组正确率对比
P004:S001|STRUCT|RC8|表 1：组别 | 正确率
#PASS1 n=CITE:14 OWN:15 STRUCT:5 AMBIG:2
```

## 异常

| 情况 | 输出 |
|-|-|
| 行缺 `P###:S###` | `#ERROR BAD_INPUT line=NN`，整批停止 |
| 段号不连续 | 照常输出，末行加 `#WARN GAP P###` |
| 乱码或 OCR 噪声 | 该句 `AMBIG`/`R9`，末行加 `#WARN NOISE n=x` |
| 输入为空 | `#ERROR EMPTY` |
| 输出接近上限 | 先输出汇总行再停，加 `#TRUNCATED` |

## 预算

一次请求覆盖一篇论文（输入 ≤ 14k tokens）。超出按章节切块，每块一次请求，块首行加 `#BATCH k/n`。
