# GB/T 7714—2015 著录规则（顺序编码制）

来源：GB/T 7714—2015《信息与文献 参考文献著录规则》。条目内标点用半角。

## 1 文献类型标识

| 标识 | 类型 | 标识 | 类型 |
|-|-|-|-|
| M | 专著 | J | 期刊 |
| C | 论文集 | D | 学位论文 |
| N | 报纸 | R | 报告 |
| S | 标准 | P | 专利 |
| A | 析出文献 | Z | 其他 |
| DB | 数据库 | CP | 计算机程序 |
| EB | 电子公告 | | |

载体标识附在类型后：`/OL` 联机网络、`/CD` 光盘、`/MT` 磁带、`/DK` 磁盘。例：`[J/OL]`、`[EB/OL]`、`[M/CD]`。

## 2 条目骨架

| 类型 | 骨架 |
|-|-|
| 期刊 | 作者. 题名[J]. 刊名, 年, 卷(期): 起页-止页. |
| 期刊（网络） | 作者. 题名[J/OL]. 刊名, 年, 卷(期): 起页-止页. DOI:10.xxxx/xxxx. |
| 专著 | 作者. 书名[M]. 版次. 出版地: 出版者, 年: 起页-止页. |
| 专著析出 | 作者. 析出题名[A]//专著作者. 书名. 出版地: 出版者, 年: 起页-止页. |
| 会议论文 | 作者. 题名[C]//编者. 论文集名. 出版地: 出版者, 年: 起页-止页. |
| 学位论文 | 作者. 题名[D]. 保存地: 保存单位, 年. |
| 标准 | 标准号 标准名称[S]. 出版地: 出版者, 年. |
| 报告 | 作者. 题名[R]. 出版地: 出版者, 年. |
| 专利 | 专利所有者. 题名: 专利国别, 专利号[P]. 公告日期. |
| 电子资源 | 作者. 题名[EB/OL]. (更新日期)[引用日期]. URL. |
| 报纸 | 作者. 题名[N]. 报纸名, 年-月-日(版次). |

## 3 作者

- 中文：`张三, 李四, 王五, 等.`
- 英文：`SMITH J, BROWN L, WANG H, et al.` 姓全拼大写，名取首字母，不加点。
- 作者 ≤ 3 全部列出；> 3 列前 3 位，后加 `, 等`（中文）或 `, et al`（英文）。
- 编者：`主编` → 后加 `, 编.`；英文 `, ed.`。
- 无作者：以题名起首。

## 4 标点与空格

- 条目内分隔：`作者. 题名[类型]. 刊名, 年, 卷(期): 页.` 半角，逗号、冒号后加一个空格。
- 条目末尾用 `.`（中文条目可用 `．`），不留多余空格。
- 卷期：有卷有期 `12(3)`；只有期 `(3)`；无卷期可省。
- 页码：`12-25`；单页 `12`。
- 多条引用合并：连续 `[3-5]`，不连续 `[3,5]`。

## 5 DOI 与 URL

- DOI 可著录，格式 `DOI:10.xxxx/xxxx`，放在页码之后。
- 网络文献必著录引用日期：`(2020-01-02)[2021-03-04]. https://...`。
- `[J/OL]`、`[EB/OL]` 的载体标识不可省。

## 6 未核项标注

作者自校时无法核实的内容，条目后加注释，不进正文：

```
[12] 张伟. 某题名[J]. 某刊, 2019, 41(2): 88-95.  ← 卷期待核
```

标注词表：`卷期待核` `页码待核` `DOI 待核` `刊名缩写待核` `作者名待核` `年份待核`。
