# 引用判定规则（章节 + 信号词）

输入：`P###:S###` 编号句子 + 所属章节。
输出：每句一个类别，见第 5 节。

## 1 章节表

引用列：`必`（多数句子需要来源）/`常`（部分句子）/`少`/`无`（不得出现标记）。

| 章节 | 引用 | 判据 |
|-|-|-|
| 题名 | 无 | 不出现标记 |
| 摘要 | 无 | 不标注，整节跳过 |
| 关键词 | 无 | 不标注 |
| 引言 | 必 | 领域背景、前人方法、研究缺口 |
| 相关工作/研究现状 | 必 | 逐条归属前人工作 |
| 理论基础 | 必 | 定义、定理、公式、量表来源 |
| 方法/材料与方法 | 常 | 借用方法、数据集、量表、标准要引；本文参数不引 |
| 结果 | 少 | 本文数据不引；与文献对比时引 |
| 讨论 | 必 | 支持/反驳的文献、机制来源 |
| 结论 | 少 | 本文结论不引；点名比较时引该半句 |
| 局限与展望 | 少 | 指向前人未解问题时引 |
| 附录 | 少 | 转载他人推导或数据时引 |
| 致谢/基金/贡献/利益冲突/数据可得性 | 无 | 声明区，不标注 |
| 图表题注 | 少 | 改自、转载他人图表时引 |
| 脚注 | 常 | 脚注制下引用落在脚注 |

不参与判定：参考文献表、目录、页眉页脚、作者简介、投稿信。

## 2 信号词

必引（他人内容）：
- 中：研究表明、研究发现、已有研究、前人研究、据…报道、据…统计、有学者提出、X 等、被认为、已有证据显示、与…一致、与…不同、参照、借鉴、引自、改自、参见
- 英：studies have shown、research indicates、it has been reported、evidence suggests、previous work、prior studies、as demonstrated by、according to、in line with、consistent with、in contrast to、adapted from、see also

不引（本文内容）：
- 中：本文、本研究、本实验、我们、笔者、课题组、结果表明、数据显示、如表 N 所示、本文提出、本文构建、经测定、实测、综上、由此可见、本文的局限
- 英：we、our、this study、the present study、the current work、herein、we propose、we find、our results show、measured in this work

结构性（不涉及引用）：
- 中：首先、其次、最后、下面、如下所述、本节、如图 N 所示、见表 N、本文结构安排如下、致谢、基金、作者贡献、利益冲突、数据可得性、伦理批号
- 英：the remainder of this paper、Section 2 reviews、as illustrated in Fig. N、Acknowledgements、Funding、Author contributions、Data availability

## 3 判定顺序

命中即停。

1. 声明区、题名、摘要、关键词、参考文献表 → `STRUCT`
2. 句中有 `[n]`、`(Author, 2019)`、上标编号：
   - 内容是他人 → `CITE`，原标记留原位
   - 内容是本文数据/方法/结论 → `AMBIG`，`R6`
3. 有具体数值：主语是本文 → `OWN`；他人测得 → `CITE`
4. 主语是本文且无"与…比较" → `OWN`
5. 有第 2 节必引信号词，或人名+等/et al./年份 → `CITE`
6. 首次出现的方法名、术语、标准号、数据集、量表 → `CITE`
   - 软件、仪器、统计工具 → 不引（见第 6 节）
7. 纯过渡、导语、图表引导 → `STRUCT`
8. 落入第 4 节 R1–R8 → `AMBIG`
9. 无信号，或观点已被上文引用覆盖 → `AMBIG`，`R9`，默认不新增

## 4 理由码

| 码 | 含义 |
|-|-|
| RC1 | 转述前人结论 |
| RC2 | 他人测得的数据 |
| RC3 | 借用方法、标准、数据集、量表 |
| RC4 | 与前人结果对比或评述 |
| RC5 | 本文自测数据 |
| RC6 | 本文结论、解释、局限 |
| RC7 | 本文方法、提出物、研究定位 |
| RC8 | 结构性语句 |
| RC9 | 声明区 |
| R1 | 常识性背景，学科惯例不定 |
| R2 | 作者自引，需确认对应哪一篇 |
| R3 | 未发表数据、in press、personal communication |
| R4 | 二次转引，需换原始出处 |
| R5 | 中外文互译题名，需定原文或译名 |
| R6 | 已有标记但内容是本文自有，疑似错位 |
| R7 | 数据来自第三方，需确认归属 |
| R8 | 软件或产品名，需定引软件还是引方法 |
| R9 | 无信号，或已被上文引用覆盖，默认不新增 |

## 5 输出格式

每句一行：

```
P003:S002|CITE|RC1|研究表明睡眠不足会降低工作
```

`P###:S###` 取自输入，不自造。类别四值：`CITE` `OWN` `STRUCT` `AMBIG`。句首 20 字逐字取自原文。

末行：

```
#PASS1 n=CITE:41 OWN:63 STRUCT:12 AMBIG:5
```

漏句、多句、改句均判失败。

## 6 硬规则

1. 摘要、关键词、题名不标注。
2. 软件、仪器、统计工具不引：`使用 SPSS 26.0`、`用 PyTorch 2.1 实现` → `OWN`/`RC7`。软件本身作为研究对象时按 `CITE`/`RC3`。
3. 混合句（借用内容 + 本文参数）→ `CITE`，挂点定在借用成分之后。
4. 已有标记一律保留，不删不换号。
5. 长句按自然语言边界切分：分号之后、话语标记（首先/其次/此外/然而/因此/第一/第二…）前的逗号。切出的片段依赖上文的并回前段，见 `pass1_prep.py`。
6. 不改写、不翻译、不补句、不输出编号。
